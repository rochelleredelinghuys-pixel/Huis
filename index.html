One more step — connect Firebase

This app needs a free Firebase project to store your shared data so it works on both phones. Takes about 10 minutes, once.

  1. Go to console.firebase.google.com and create a free project.
  2. In your project, click Build → Firestore Database → Create database. Choose "Start in test mode" for now.
  3. Click the gear icon → Project settings, scroll to "Your apps", click the </> (Web) icon to register a web app.
  4. Copy the firebaseConfig object it gives you.
  5. Open index.html in a text editor, find the firebaseConfig section near the top of the file, and paste your values in over the PASTE_YOUR_... placeholders.
  6. Save the file and refresh this page (or redeploy if it's already live on Vercel).

Full step-by-step instructions, including the Firestore security rule you'll need, are in SETUP.md in the project folder.
